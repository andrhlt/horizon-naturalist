## Follow-up runtime implementation

- The follow-up adds a real native mixin at the pinned Horizon `finalize_with` call site. For natural `naturalist:bird` spawns it selects the Java fixture-backed biome pool using the shared world RNG, writes the Java `Variant` identifier, and supplies an ageable group with zero baby chance. This removes the generic Parrot variant/5% baby behavior from the Bird natural-spawn stream; non-natural reasons are excluded.
- The hook uses the Horizon SDK's documented `$local_mut:group:0` binding. The pinned optimized build succeeded on Horizon `0a875da91dbb0fdcb7ba8c42c11341aa229af51a` with build id `native-0a875da-babc6e7c3a5e` (22 seconds). This is compile and mixin-application evidence; the local GUI test process reached the control socket but exited before a reproducible entity probe, so no fixed-seed count claim is made here.
- The implementation is intentionally limited to Bird until per-species natural finalization fixtures are wired into an executable probe. The pinned engine does expose a read-only `mob_spawn_placement_check` hook after the vanilla predicate; its API can force `Default`/`Succeed`/`Fail`, but this follow-up does not invent aquatic/fluid/depth logic without a fixture-to-host query mapping. The existing aquatic and insect Java fixtures remain coverage requirements, not silently accepted parity.
- The corrected pool table has exact full biome IDs (36/36), exact Java order and weights, and no substring fallback. `minecraft:cherry_grove`, `minecraft:savanna`, and `naturalist:stellers_jay` are covered explicitly. Reproduce with `python3 tools/verify_bird_variant_pools.py`.

## Predicate hook investigation

- Horizon `mobs::spawn_rules::check_spawn_rules` computes the registered placement predicate, then calls `SpawnLevel::placement_check`; the game implementation forwards that call to the mod API's read-only `mob_spawn_placement_check` event. The event exposes `kind`, integer `pos`, `reason`, `default_result`, `LevelRef`, and mutable `SpawnCheck` (`Default`, `Succeed`, `Fail`). This is a safe species-specific seam beyond `Registrar::declare_spawn_placement`.
- The current follow-up uses that seam for the fixture-proven Hippo rule on natural spawns: require water at the spawn position or one block below, including a waterlogged block below; force failure otherwise. The pinned fixture cases cover no water, 16-block water, horizontal/vertical water, waterlogged below, generated same/cross chunk, and stone rejection. The hook is compiled in `native-0a875da-fe1b833e06f7`.
- The API deliberately gives the hook read-only host access. A selected-instance headless run (`horizon-launcher play --arg=--headless --arg=--control-socket ...`) loaded the mod and reported Naturalist entities. `/summon` is not a placement probe: Horizon's own hook documentation says summon/spawn-egg paths do not call placement checks. The old GUI-only attempt used the base nightly binary and therefore reported `naturalist:bird` unknown; no fixed-seed or Hippo runtime parity claim is made from it.

## Bird RNG finding

The modifier ordering correction is proven to remove the spawn-row-order mismatch. It does not close fixed-seed world generation: on seed `49903`, the normal-probability sample produced 3 Horizon Birds and 2 Java Birds; with controlled 0.5 probability, it produced 29 Horizon Birds and 32 Java Birds. Exact Java position overlap rose from 10 to 21 after ordering. Seed `49904` produced zero Birds on both. See `fixtures/naturalist-combined-3d513df20090.json` and the archived run logs under the bird-density audit referenced there.

These density observations do not isolate which residual draw differs. `fixtures/bird-region-java.json` provides a seed-injected five-member Java finalization sample, including each member's variant, age, follow-range bonus, handedness, and final RNG state. A matching Horizon finalization capture on the same source artifact and injected stream is needed before changing spawn RNG or group initialization. Do not treat the observed count delta alone as evidence for a particular RNG fix.
